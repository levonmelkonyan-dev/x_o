# ❌⭕ Neon Tic-Tac-Toe - Interactive Web Game

A modern, dynamic, and interactive Tic-Tac-Toe game built with React.js and styled with a futuristic neon dark-mode theme. Designed for clean user interaction  gameplay .

🚀 **[Live Demo](https://cheerful-puppy-0a3730.netlify.app/)**

---

## ✨ Features

- 🎮 **Interactive Gameplay:** Smooth X and O placement with real-time turn indicators.
- 🎨 **Neon Cyberpunk UI:** Stylish dark-mode design with vibrant neon glows and custom borders.
- 📊 **Scoreboard / Win Logic:** Automatic win and draw detection with instant score updates.
- 📱 **Fully Responsive:** Perfectly playable on smartphones, tablets, and desktop screens.

---

## 🛠️ Tech Stack & Tools

- **Frontend:** React.js, JavaScript 
- **Styling:** CSS
- **Deployment:** Netlify
